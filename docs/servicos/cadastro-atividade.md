# Cadastro de Atividade

## Objetivo

Cadastrar ou consultar atividades vinculadas a serviços.

## Caminho

`Serviços > Cadastro de Atividade`.

## Passo a passo

1. Acesse a aba **Serviços**.
2. Clique em **Cadastro de Atividade**.
3. Informe os filtros ou dados necessários.
4. Confira as informações antes de salvar, confirmar ou finalizar.
5. Finalize conforme a ação disponível na tela.

## Campos principais

| Campo | Descrição | Observações |
| --- | --- | --- |
| A definir | A definir | A definir |

## Dúvidas frequentes

| Dúvida | Orientação |
| --- | --- |
| Quando devo usar esta rotina? | Use quando o processo estiver relacionado a **Cadastro de Atividade**. |
| O que devo conferir antes de salvar? | Confira os dados obrigatórios, filtros e mensagens exibidas pelo sistema. |
