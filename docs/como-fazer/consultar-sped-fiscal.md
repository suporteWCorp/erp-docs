# Como consultar SPED Fiscal

## Pré-requisitos

- Período ou critério fiscal definido
- Acesso às rotinas fiscais ou de relatórios liberado

## Como fazer

1. Acesse a rotina relacionada ao **SPED Fiscal**.
2. Informe os critérios necessários para consulta ou geração.
3. Confira as informações exibidas.
4. Gere, consulte ou exporte conforme a ação disponível.
