# É possível realizar a inutilização de uma numeração de CT-e?

Não. Conforme a Nota Técnica 2023.001, não é mais possível inutilizar uma numeração de CT-e que não tenha sido utilizada. Caso exista uma numeração não utilizada, ela permanecerá apenas como uma quebra na sequência, sem necessidade de inutilização.
