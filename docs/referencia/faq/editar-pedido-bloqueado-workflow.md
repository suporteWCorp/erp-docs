# Não estou conseguindo editar um pedido mesmo estando pendente. O que faço?

Verifique se o Workflow do pedido está configurado para bloquear a edição.

## Onde verificar

No cadastro do Workflow, confira se o checkbox **Bloquear edição do Pedido** está selecionado.

Para visualizar o cadastro do Workflow, clique na lupa ao lado do campo onde o Workflow é selecionado.
