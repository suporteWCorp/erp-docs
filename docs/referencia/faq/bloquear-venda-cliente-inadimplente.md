# Consigo bloquear a venda se o cliente tiver pagamentos em atraso?

Sim. O bloqueio pode ser configurado no cadastro do cliente.

## Caminho no WCorp

1. Acesse o cadastro do cliente.
2. Abra a aba **Comercial**.
3. Clique em **Utilizar configurações Customizadas para este cliente**.
4. Marque o checkbox **Bloquear vendas caso o Cliente possua pagamentos em atraso**.
5. Salve o cadastro.
