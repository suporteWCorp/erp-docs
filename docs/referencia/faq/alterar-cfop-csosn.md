# Precisava mudar CFOP e CSOSN de um produto. Como faço?

A alteração deve ser feita na Natureza de Operação utilizada pela nota.

## Caminho no WCorp

1. Acesse o cadastro da **Natureza de Operação** utilizada.
2. Localize a **Regra Fiscal** correspondente.
3. Altere o **CFOP**.
4. Altere o **CSOSN**, que é a Situação Tributária de ICMS.
