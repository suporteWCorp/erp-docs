# É possível alterar alguma informação de uma nota fiscal já emitida?

Não. Depois que a NF-e é autorizada pela SEFAZ, suas informações não podem ser alteradas diretamente. Quando necessário, é preciso cancelar a nota, se ainda estiver dentro do prazo, ou utilizar o documento de ajuste aplicável ao caso.
