# Tem como deixar um percentual de comissão definido para o cliente?

Sim. O percentual pode ser definido no cadastro do cliente.

## Caminho no WCorp

1. Acesse o cadastro do cliente.
2. Abra a aba **Comissões**.
3. Clique em **Adicionar comissão**.
4. Informe o percentual de comissão.
5. Salve o cadastro.
