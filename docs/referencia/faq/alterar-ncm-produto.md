# Como altero o NCM de um produto?

O NCM é alterado no cadastro do material.

## Caminho no WCorp

1. Acesse **Materiais > Materiais**.
2. Abra o cadastro do material.
3. Localize o campo **NCM**, logo abaixo de **Origem**.
4. Informe o código correto conforme orientação da contabilidade.
5. Salve o cadastro.
