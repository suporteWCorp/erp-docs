# Um pedido já faturado pode ser alterado?

Não. Após o faturamento, o pedido não pode ser alterado diretamente. Para ajustar quantidade, valor, produto ou outras informações, é necessário primeiro cancelar a nota fiscal vinculada e, depois, realizar as alterações necessárias no pedido.
