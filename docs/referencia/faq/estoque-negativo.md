# O sistema permite estoque negativo?

Depende da configuração do material. Se a opção **"Habilitar Controle de Estoque"** estiver marcada no cadastro do material, o sistema bloqueia vendas que resultariam em saldo negativo. Se estiver desmarcada, a venda pode ser realizada mesmo sem saldo disponível.
