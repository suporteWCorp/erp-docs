# Referência do objeto não definida para uma instância de um objeto

## Mensagem apresentada

Ao tentar adicionar um material ao pedido e salvar, o sistema apresenta:

> Ocorreu um erro não esperado. Referência do objeto não definida para uma instância de um objeto

## Verificação conhecida

Verifique se o lote de estoque utilizado para consumir estoque, no local de armazenagem usado, está cadastrado em outra empresa.

## Observação

Essa é uma verificação conhecida para esse cenário. Ela não deve ser tratada como regra universal para todas as ocorrências da mensagem.
