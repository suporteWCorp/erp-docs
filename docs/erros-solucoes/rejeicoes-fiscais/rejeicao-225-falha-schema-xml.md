# Rejeição 225 — Falha no Schema XML

<p class="wc-rejection-meta"><span class="wc-rejection-doc-badge">NF-e</span></p>

<p class="wc-rejection-message"><strong>Mensagem SEFAZ</strong>Rejeição 225: Falha no Schema XML.</p>

## Como a SEFAZ interpreta

O XML enviado não atende ao schema ou ao layout exigido pela SEFAZ.

## Como isso acontece no WCorp

O material revisado orienta que o Suporte deve analisar o ID da Nota Fiscal quando essa rejeição ocorrer.

## Como verificar

1. Identifique a NF-e rejeitada.
2. Separe o ID da Nota Fiscal para análise.
3. Encaminhe ao Suporte quando a causa não estiver evidente.

## Como corrigir

O Suporte deve verificar a NF-e a partir do ID da Nota Fiscal.

## Observações

Esta rejeição continua sendo fiscal, mesmo quando a análise precisa ser feita pelo Suporte.
