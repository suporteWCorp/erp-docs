# Carta de Correção

A tela **Carta de Correção** é utilizada para emitir uma Carta de Correção Eletrônica (CC-e) para uma NF-e autorizada.

## Caminho

`Faturamento > Carta de Correção`

## Como utilizar

1. Clique em **Adicionar (F1)** para iniciar uma nova Carta de Correção.
2. No campo **Nota Fiscal**, selecione a NF-e que será corrigida.
3. No campo **Correção**, informe o texto com a correção necessária.
4. Confira as informações e clique em **Salvar (F2)**.
5. Clique em **Transmitir para o Sefaz** para enviar a Carta de Correção.
6. Após a transmissão, acompanhe o **Status da Carta de Correção** na listagem da tela.

## Campos principais

| Campo | Descrição |
| --- | --- |
| **Nota Fiscal** | NF-e à qual a Carta de Correção será vinculada. |
| **Data/Hora** | Data e hora do registro da Carta de Correção. |
| **Status** | Situação atual da Carta de Correção no processo de envio. |
| **Correção** | Texto que descreve a informação que precisa ser corrigida. |

## Consulta

Na parte superior da tela é possível consultar as Cartas de Correção já cadastradas. A listagem apresenta:

- **Id**
- **Nota Fiscal**
- **Data**
- **Status da Carta de Correção**

## Condições de uso

A própria tela apresenta as condições de uso da Carta de Correção. Antes da transmissão, verifique se a alteração pretendida pode ser realizada por CC-e.

A Carta de Correção não deve ser utilizada para alterações relacionadas a:

- variáveis que determinam o valor do imposto, como base de cálculo, alíquota, diferença de preço, quantidade ou valor da operação;
- dados cadastrais que impliquem mudança do remetente ou do destinatário;
- data de emissão ou data de saída.
